开始使用

为已有项目安装飞书机器人

已有治理项目无需重装或升级框架，可从安装器首页直接进入飞书机器人配置链。

#从安装器进入

  1. 双击安装器。
  2. 选择“已有项目添加机器人”。
  3. 选择已经安装 AIIGovernance 的项目根目录。
  4. 安装器检测到治理标记后直接进入机器人接入页面。

#创建飞书应用

在飞书开放平台创建智能体应用，保存 App ID 和 App Secret。安装器中的“查看示例”会打开三步图文说明。

凭据保护
App Secret 不写入向导状态和安装日志，只在验证与配置装配期间保存在内存中。

#确认消息身份

  1. 输入 App ID 和 App Secret，并执行真实凭据校验。
  2. 按提示向机器人发送第一条消息。
  3. 安装器通过隔离探针捕获你的 open_id。
  4. 把机器人的 allow_from 收窄到该身份。

#启动与验证

安装器注册或复用现有 cc-connect 服务，然后要求发送第二条消息完成端到端验证。

已有 cc-connect
如果已有二进制与安装包一致，安装器直接安全复用，不覆盖运行中的 EXE；版本不同且文件被占用时，会提示先停止 cc-connect 计划任务再重试。
