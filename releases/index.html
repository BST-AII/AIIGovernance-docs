版本与发布说明

安装器使用语义化版本，并通过 lite 分支的 GitHub Actions 自动测试、构建和发布。

#0.3.x

  • 首次安装与已有项目升级入口
  • 版本检测、Settings 备份和升级说明
  • 项目级安全卸载
  • 已有项目独立添加飞书机器人
  • 已有 cc-connect 相同版本安全复用
  • EXE Windows 文件版本和自动 GitHub Release

#自动版本规则

推送到 lite 后，构建流程先测试和生成安装器；源码版本未发布时直接发布，已有对应 Tag 时自动递增 PATCH。成功后生成 Tag、ZIP、EXE 和 SHA256。

#发布产物

  • AIIGovernance-Setup-lite-vX.Y.Z.zip
  • 单文件 Windows 安装器
  • SHA256 校验文件
  • CHANGELOG 更新说明

#查看历史版本

完整版本变更记录保存在仓库根目录的 CHANGELOG.md，正式安装包位于 GitHub Releases。
