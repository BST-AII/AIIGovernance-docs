安全卸载治理框架

卸载只拆除安装器管理的治理接线和运行时，保留项目业务数据与可审阅的 Git 变更。

#进入卸载

  1. 运行安装器并选择“升级已有项目”。
  2. 选择已安装治理框架的项目。
  3. 在版本检查页面选择“卸载治理框架”。
  4. 阅读删除与保留清单后再次确认。

#会被移除

  • AIIGovernance 与 Wildskills submodule
  • AIIG Hooks 接线
  • 安装器接入的项目 Skills
  • 项目内便携 Python
  • 安装器管理的元数据

#会被保留

  • project_profile.yaml
  • records/ 与审计证据
  • 用户权限配置
  • 全局项目 Trust 记录

#安全保护

如果治理 submodule 内存在未提交修改，卸载会停止，不会强制删除。Git 删除结果保留在项目工作区或暂存区，由维护者审核后提交。
