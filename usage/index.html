如何调用治理框架与 Skills

治理框架通常由 Claude Code 在项目会话中自动加载；用户也可以明确指定职能、Skill 和验收要求。

#进入治理项目

cd your-project
claude

新会话读取项目根目录的 CLAUDE.md，再进入治理框架的基本法与会话初始化流程。

#自然语言自动调用

直接描述任务即可，例如：

帮我修复登录接口的超时问题，验收标准是现有测试通过并新增一个超时回归测试。

框架会将任务路由到 coding 职能，读取编码业务法，建立任务记录并按工作流执行。

#明确指定 Skill

需要固定能力时可以直接点名：

请使用 security-review Skill 检查这次认证模块修改，并列出可复现证据。

Agent 应先读取对应 Skill 的说明，再在治理规则限定的范围内执行。

#手动运行核验

.\tools\python\python.exe .governance\AIIGovernance\tool\check.py --lint
.\tools\python\python.exe .governance\AIIGovernance\tool\check.py --run
